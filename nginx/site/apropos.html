Architecture technique

Trois conteneurs Docker orchestrés par Docker Compose.

Flux d'une requête

Le navigateur ne parle qu'à Nginx, qui redirige les appels API vers Flask, lequel interroge MySQL.

🌐NavigateurHTML / CSS / JS
→
⚡NginxPort 80 · Proxy
→
🐍Flask APIPort 5000 · Gunicorn
→
🐬MySQLPort 3306 · Volume
⚡

Conteneur Nginx

Sert les pages statiques et agit comme reverse proxy : toute requête /api/ est transmise au conteneur Flask.

🐍

Conteneur Flask

API REST qui implémente les 5 fonctions bancaires et communique avec MySQL par le réseau Docker.

🐬

Conteneur MySQL

Stocke comptes et transactions. Un volume nommé garantit la persistance des données.
